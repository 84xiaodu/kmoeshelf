# Kmoe 搜索路由修复设计

日期：2026-08-17  
状态：书面设计已确认

## 1. 问题与证据

当前服务向已登录镜像请求：

```text
/l/{keyword},all,all,sortpoint,all,all,none/{page}.htm
```

真实站点对该路径不再应用关键词。使用“琉璃龍龍”和一个不存在的随机字符串进行只读对照，两次请求均返回相同的 21 条结果、相同的前五个漫画 ID，并报告 890 页，因此当前 Web 看起来像“搜什么都返回全部”。

当前页面中的搜索表单声明 `GET https://kxx.moe/list.php`，字段名为 `s`。在该表单指定的主机上请求相同关键词时，Kmoe 会返回自身的模糊匹配结果；不存在的关键词返回合法空结果，其分页总数为 `0`。

## 2. 目标与非目标

目标：

- 使用 Kmoe 当前声明的搜索入口，而非固化已失效的列表路径。
- 完整保留 Kmoe 自身的模糊匹配、别名及繁简体行为，不在本地二次过滤。
- 保留现有 `/api/kmoe/search`、`SearchPage` 与前端交互契约。
- 将合法空结果与站点协议变化明确区分。
- 不允许页面把搜索请求导向 Kmoe 镜像白名单之外的主机。

非目标：

- 不建立本地漫画搜索索引。
- 不抓取全部书库后在本地筛选。
- 不修改订阅、详情或下载协议。
- 不把 `kxx.moe` 永久固化为唯一搜索主机。

## 3. 搜索流程

搜索仍完全位于 `src/kmoe_subscriptions/kmoe/` 适配器内：

1. 使用已登录客户端读取当前镜像的搜索页面或首页。
2. 从 HTML 中提取唯一可接受的搜索表单。
3. 验证表单必须满足：
   - 方法为 `GET`；
   - action 使用 HTTPS；
   - 主机属于 `DEFAULT_MIRRORS`；
   - 路径严格为 `/list.php`；
   - 搜索字段为 `s`。
4. 让客户端切换到通过白名单验证的搜索主机，并把当前会话的最小 Cookie 集重新限定到该主机；不得向白名单之外复制 Cookie。
5. 第一页请求 `/list.php?s={query}`；第二页起使用同一可信搜索主机声明的规范分页族 `/l/{query},all,all,sortpoint,all,all,none/{page}.htm`。不得把该分页路径发送到活动镜像或其他镜像。
6. 使用现有受约束的 JavaScript 调用解析器生成 `SearchPage`。

若搜索表单缺失、出现多个互相冲突的目标、目标不可信或结果结构不符合契约，返回 `site_changed`。系统不得回退到会忽略关键词的全量列表路径。

## 4. 分页与空结果

- 非空结果继续要求 `current_page >= 1`、`total_pages >= current_page`。
- Kmoe 对不存在的关键词会返回受支持的结果结构、`page_now = 1`、零条 `disp_divinfo` 结果以及 `total_pages = 0`。
- 仅在“请求第 1 页且结果为空”的组合下，将远端 `0` 规范化为 API 的 `total_pages = 1`，从而保持既有 `SearchPage` 契约和前端“第 1 / 1 页”显示。
- 第 2 页或更高页码若返回零总页数，仍视为分页契约不匹配，而非合法空结果。

## 5. 组件边界

- `parser.py` 新增只负责解析和验证搜索表单目标的纯函数。
- `catalog.py` 负责编排“发现目标 → 设置受信任搜索主机 → 发出搜索请求 → 解析结果”。
- `client.py` 新增受镜像白名单约束的主机切换能力，集中处理 Cookie 重新限定、速率限制与网络错误；不引入通用任意 URL 请求能力。
- API 和 React 页面无需改变；它们只会收到正确筛选后的现有 `SearchPage`。

## 6. 错误与安全

- 不输出 Cookie、搜索页面正文或用户凭据。
- 表单 action 即使来自 Kmoe 页面，也必须经过协议、主机和路径三重验证。
- 搜索目标由特定表单 action 决定，第一页和分页请求都固定在该目标主机且禁止跨镜像重放；目标主机网络失败时返回现有网络错误，由管理员重试。协议或网络失败均不可降级成全量列表。
- 发现页与结果页的主机可以不同，漫画详情仍使用已保存的活动镜像与相对漫画 ID，不受搜索主机切换影响。

## 7. 测试与验收

自动化测试覆盖：

- 从当前镜像页面发现白名单内的 `kxx.moe/list.php`。
- 拒绝 HTTP、外部主机、错误路径、POST 和缺少 `s` 字段的表单。
- 第一页搜索请求携带 `s`；后续页请求同一可信目标主机的规范 `/l/.../{page}.htm` 路径，且不跨镜像重放。
- 两个模拟关键词返回不同结果集。
- Kmoe 合法零结果规范化为第 `1/1` 页。
- 非法零页分页及站点结构变化返回 `site_changed`。
- 现有搜索转义、详情和下载测试保持通过。

真实站点验收使用一个已知漫画名和一个随机不存在字符串：前者应返回 Kmoe 的模糊匹配结果，后者应显示空状态；二者不得再返回相同的全量书库页。
