## Variant: 温暖编辑书架

### Design stance
以一本主推作品和横向书架建立阅读节奏，管理功能退居二线。

### Key choices
- Layout: 窄图标栏、编辑主推区、规则封面网格
- Typography: 衬线大标题 + 系统无衬线正文
- Color: 暖纸色、炭黑、陶土红
- Interaction: 推荐来源筛选、加入书架、详情反馈

### Trade-offs
- Strong at: 层次清晰、推荐理由可见、适合每日打开
- Weak at: 同屏作品数量较少

### Best for
- 想把 KmoeShelf 当作个人数字漫画书架，而非任务管理后台
