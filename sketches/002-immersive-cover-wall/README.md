## Variant: 沉浸封面墙

### Design stance
把“发现下一本漫画”作为首页唯一主任务，用高密度封面墙弱化后台感。

### Key choices
- Layout: 固定侧栏、瀑布流封面、右侧详情抽屉
- Typography: 大号紧凑无衬线标题
- Color: 深色画布、荧光黄绿单一强调色
- Interaction: 来源筛选、详情抽屉、加入书架

### Trade-offs
- Strong at: 同屏浏览量高、封面主导、发现感强
- Weak at: 下载与检查状态不如编辑式布局醒目

### Best for
- 经常浏览推荐、希望快速扫封面并连续打开详情的用户
